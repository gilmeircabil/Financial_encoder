## 2. Security and Privacy Controls

- **100% Offline Vault Guarantee**: Zero external network sockets, zero analytics SDKs, zero telemetry.
- **Electron Hardening**: `contextIsolation: true`, `nodeIntegration: false`, `sandbox: true`, `webSecurity: true`, child window creation denied.
- **SQL Injection Defense**: Prepared statements with parameterized inputs throughout the query layer.
- **Disaster Recovery**: Automated 24h startup backups with 30-day retention; safety snapshots created before database restores or wipes.

## 5. Deployment, Rollback, and Backup Instructions

### Production Build
```bash
# Compile renderer and main process
npm run build

# Package unpacked directory for local verification
npm run dist:dir

# Build final Windows installer (.exe)
npm run release
```

### Database Recovery & Backup
- **Live Database:** `%APPDATA%\Acorn\database.db`
- **Automated Backups:** `%APPDATA%\Acorn\backups\` (retention: 30 days)
- **Restore:** Handled in-app under **Settings → Backups** or by replacing `database.db` with an uncorrupted `.febak` archive when the application is closed.

---

## 6. Known Limitations

- **Storage at Rest (`SEC-01`)**: SQLite database is unencrypted on the local filesystem. BitLocker or OS-level file encryption is recommended for high-security environments.
- **Vendor Chunk Size (`DBG-09`)**: Client bundle is ~759 kB due to PDF.js and Recharts. Does not impact desktop Electron performance.
